Änderung vom 9. September 2026

Der Schweizerische Bundesrat

verordnet:

I

Die Berufsbildungsverordnung vom 19. November 20031 wird wie folgt geändert:

Art. 46 Lehrpersonen für die schulische Grundbildung und die Berufsmaturität

(Art. 46 BBG)

1 Lehrpersonen für die schulische Grundbildung und die Berufsmaturität müssen über eine Lehrbefähigung für die Sekundarstufe II verfügen.

2 Die Lehrpersonen für die schulische Grundbildung und die Berufsmaturität sind:

a.
Lehrpersonen für Berufskunde;
b.
Lehrpersonen für Allgemeinbildung;
c.
Lehrpersonen für Sportunterricht;
d.
Lehrpersonen für Fächer in der Berufsmaturität.

3 Lehrpersonen für Berufskunde verfügen über eine Lehrbefähigung für die Sekundarstufe II, wenn sie über eine betriebliche Erfahrung von sechs Monaten sowie über folgende Qualifikationen verfügen:

a.
eine berufspädagogische Bildung auf Hochschulstufe von:
1.
1800 Lernstunden bei hauptberuflicher Bildungstätigkeit,
2.
300 Lernstunden bei nebenberuflicher Bildungstätigkeit;
b.
einen entsprechenden Abschluss der höheren Berufsbildung oder einer Hochschule.

4 Lehrpersonen für Allgemeinbildung verfügen über eine Lehrbefähigung für die Sekundarstufe II, wenn sie über eine betriebliche Erfahrung von sechs Monaten sowie über eine der folgenden Qualifikationen verfügen:

a.
eine berufspädagogische Bildung auf Hochschulstufe von 1800 Lernstunden und einen Abschluss auf Hochschulstufe; oder
b.
eine berufspädagogische Bildung auf Hochschulstufe von 300 Lernstunden und eine Lehrbefähigung in der obligatorischen Schule oder eine gymnasiale Lehrbefähigung, beide ergänzt durch eine Qualifikation in Allgemeinbildung mit den Kompetenzen des entsprechenden Lehrplans.

5 Lehrpersonen für Sportunterricht verfügen über eine Lehrbefähigung für die Sekundarstufe II, wenn sie über eine betriebliche Erfahrung von sechs Monaten sowie über eine der folgenden Qualifikationen verfügen:

a.
eine berufspädagogische Bildung auf Hochschulstufe von 1800 Lernstunden und einen Abschluss auf Hochschulstufe im unterrichteten Fachgebiet;
b.
eine berufspädagogische Bildung auf Hochschulstufe von 300 Lernstunden und eine gymnasiale Lehrbefähigung für Sportunterricht; oder
c.
eine berufspädagogische Bildung auf Hochschulstufe von 300 Lernstunden und eine Lehrbefähigung in der obligatorischen Schule, ergänzt durch eine Zusatzqualifikation für Sportunterricht.

6 Lehrpersonen für Fächer in der Berufsmaturität verfügen über eine Lehrbefähigung für die Sekundarstufe II, wenn sie über eine betriebliche Erfahrung von sechs Monaten sowie über eine der folgenden Qualifikationen verfügen:

a.
eine berufspädagogische Bildung auf Hochschulstufe von 1800 Lernstunden und einen Abschluss auf Hochschulstufe im unterrichteten Fachgebiet; oder
b.
eine berufspädagogische Bildung auf Hochschulstufe von 300 Lernstunden und eine gymnasiale Lehrbefähigung im unterrichteten Fachgebiet.
Art. 47 Sachüberschrift und Abs. 3

Betrifft nur den französischen Text.

3 Wer weniger als durchschnittlich vier Wochenstunden unterrichtet, unterliegt nicht den Vorschriften nach den Artikeln 45 Buchstabe c Ziffer 2 und 46 Absatz 3 Buchstabe a Ziffer 2.

Art. 76a Lehrbefähigung für das Erteilen von Sportunterricht

Das nach bisherigem Recht erworbene eidgenössische Turn- und Sportlehrerdiplom I oder II, das Diplom «Sportlehrerin FH» oder «Sportlehrer FH» sowie das Bachelordiplom in Sport der Eidgenössischen Hochschule für Sport Magglingen gelten als Lehrbefähigung für Lehrpersonen im Sportunterricht im Sinne von Artikel 46 Absatz 5.
